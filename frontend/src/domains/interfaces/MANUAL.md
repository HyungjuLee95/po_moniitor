# Interfaces MANUAL
표시명과 기술키·namespace를 함께 보여 충돌을 구분한다.

시스템 별 채널 정보는 `비즈니스 시스템 선택 → 채널 목록 → 채널 상세` 순서를 유지하며 상세 속성은 최대 24개를 우선 표시한다.

`09 시스템 연결 관계`는 RTIMS 인터페이스 매핑에서 송신 시스템→수신 시스템 경로와 그 사이의 인터페이스·Namespace를 묶어 보여준다. `10 Namespace 인벤토리`는 SAP InterfaceMonitor에서 인터페이스명, Namespace, 방향, 송신/수신 시스템과 Operation을 목록으로 조회한다.
