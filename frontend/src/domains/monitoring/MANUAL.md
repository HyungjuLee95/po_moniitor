# Monitoring MANUAL
지표의 단위·기준 시각·집계 window를 화면에 명시하고 null과 부분 실패를 안전하게 표시한다. 평균 카드 상세에는 policy 기준을 초 단위로 표시하고 메시지별 elapsed와 Message ID를 제공한다.

- 대시보드 KPI는 총 메시지량·성공률·실패 건수·평균 응답을 기본으로 한다.
- 트래픽 그래프의 기본 조건은 `전체(POP+PMP)`, `1시간`이다. 시간 모드는 오늘 `00:00:00~23:59:59`의 24개 bucket을 표시하고, `1일`을 고르면 최근 7일 일별 합계를 표시한다.
- 서버 dropdown에서 POP 또는 PMP를 개별 조회할 수 있다. 전체 조회 중 일부 서버가 실패하면 성공한 서버 데이터만 표시하고 부분 실패를 안내한다.
- 막대에 마우스를 올리거나 키보드 focus를 주면 bucket 시간, 메시지량, 요청·응답을 합한 총 메시지 크기를 표시한다.
- API에 데이터가 없는 시간·날짜도 0 bucket으로 보완해 축 범위를 유지한다.
- 시스템 처리 결과는 `전체/정상/오류/Delivering` 필터를 제공한다.
- Queue 카드에는 대기 건수와 working/max Thread를 함께 표시한다.
- 리소스 화면은 CPU·Memory를 자원별 독립 카드로 흩뜨리지 않고 노드 단위 통합 보드에서 현재/최대 사용률을 겹친 막대로 비교한다.
- 대시보드용 summary, throughput, system statistics, Queue, 최근 메시지는 독립 로딩하며 15분마다 기존 화면을 유지한 채 백그라운드 갱신한다. 전용 실시간 인터페이스 화면의 짧은 갱신 주기와 구분한다.
