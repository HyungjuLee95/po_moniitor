# Dashboard SKILL

Verify that an API which never responds stops showing its loading state after 12 seconds without blocking or clearing other widgets.
위젯을 독립 렌더링하고 숨김·순서·밀도·reset·save를 확인한다. 최초 독립 로딩, 느린 API가 빠른 API를 막지 않는지, 15분 백그라운드 갱신 중 기존 데이터 유지와 부분 실패 격리를 확인한다. 메뉴 변경 시 카테고리 순서, 역할별 빈 카테고리 제거, drawer 닫기, 즐겨찾기 고정과 사용 횟수 정렬을 확인한다. 좁은 화면에서 순서와 정보 손실을 점검한다.
