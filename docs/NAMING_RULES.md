# 네이밍 규칙

- Python 파일·함수·변수: `snake_case`
- Python 클래스: `PascalCase`
- React 컴포넌트·타입: `PascalCase`
- TypeScript 함수·변수: `camelCase`
- 환경 변수: `UPPER_SNAKE_CASE`
- API 경로: 복수형 소문자 kebab-case
- PostgreSQL schema/table/column/index: 소문자 `snake_case`
- 역할 코드와 서버 SID: 대문자

도메인 이름은 `auth`, `configuration`, `monitoring`, `channels`, `messages`, `incidents`, `collectors`, `interfaces` 중 하나를 우선 사용합니다. 새 이름을 만들기 전에 기존 도메인 확장 가능성을 먼저 검토합니다.
