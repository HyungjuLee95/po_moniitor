# Auth

`DEMO_MODE=true` starts with one built-in account only: `admin` with the password configured by `DEMO_ADMIN_PASSWORD`. Operator and viewer demo accounts are not pre-seeded; create additional users from the admin user-management screen when needed.
로그인, JWT 발급, 사용자 생성·활성화·역할·접근 서버·관리자 초기화, 사용자 직접 변경과 관리자 승인형 비밀번호 찾기를 담당한다. 전체 계약은 `API.md`를 따른다.
