# Channels
Communication Channel 인벤토리·실시간 상태·상세·채널별 RTIMS 통계와 메시지 이력, 권한 기반 제어를 담당한다.

주요 API는 `/channels`, `/channels/inventory`, `/channels/statistics`, `/channels/message-history`, `/channels/control`, `/channels/batch-control-stream`, `/channels/bulk-export`, `/channels/bulk-preview`다. 전체 계약은 `API.md`를 따른다.
